# 编辑口径

这份文件回答的是"内容怎么写才不水"。schema 决定页面长什么样，这里决定它值不值得学。

## 一、选句：什么句子配得上一张卡

**值得做卡的三个信号**

1. **一句里叠了两层以上语法**。`なくせぬ` = 可能形 + 文言否定；`なれるさ` = 可能形 + 终助词。这种句子讲一次抵三句。
2. **中文直译会走样**。`嘘じゃない` 直译"不是谎话"，实际是"都是真的"。学习者自己看翻译永远学不会。
3. **有日语特有的"句法习惯"**。宾语甩到句末（`つかめ! 描いた夢を`）、句尾用 `から` 留白、用片假名做强调（`コト`）。

**不值得做卡的信号**

- 纯名词短语（`青い星に`）——没有语法可讲。
- 只有一个 N4 词汇、没有句型的句子——那是词表的活。
- 歌词里重复出现的段落——同一句只做一张卡，别做两遍。

**抽卡的分布**：Aメロ 多讲"读法"（助词、时态），Bメロ 多讲"命令形/意志形"，サビ 多讲"句型与语气"。全曲 16–24 张，Aメロ 和 サビ 各占三分之一最匀。

## 二、卡片：`g` 和 `n` 必须分工

这是整套模板最容易被写坏的地方。

| 字段 | 回答的问题 | 长度 |
|---|---|---|
| `g`（语法） | 这个句型**是什么、怎么接** | 30–60 字 |
| `n`（语感） | 唱到这一句**要注意什么** | 30–60 字 |

**正例**

> `g`：**〜たり〜たりする**：从一堆动作里挑两三个举例，暗示"还有别的"。歌词只留了一个「たり」，第二个被省略了。
> `n`：「コト」特意写成片假名，不是错字，是为了让这个词在视觉上被顶出来，唱到这里语气也更实。

**反例**（`n` 把 `g` 又说了一遍）

> `g`：命令形，つかむ → つかめ。
> `n`：这里是命令形，表示"抓住"。

`n` 的四个合法方向，选一个写：

1. **唱法**：哪里换气、哪个音要拖满、哪个促音卡鼓点。
2. **书写**：片假名强调、送假名、旧字。
3. **语气**：`さ` 像中文的"嘛"、`から` 收得轻。
4. **对比**：`逢う` vs `会う`、`壊す` vs `崩す`、`だけ` vs `にしか`。

写不出 `n`，说明这个句子不值得做卡，换一句。

## 三、词表：收词与分级

**收**：这首歌里出现、且会挡住 N3 学习者理解的词。动词优先于名词，因为动词带活用。

**不收**：`する` `いる` `ある` `こと` `もの` `とても` 这类。也不收只在歌词里出现一次、且不影响理解的生僻词。

**分级保守原则**：拿不准就给低一级。

| 情况 | 给 |
|---|---|
| 日常会话高频、N4 教材里出现过 | N4 或 N5 |
| 书面语/文学语（`宿る` `鼓動` `逢う` `たくましい`） | N2 或 N1 |
| 抽象名词（`一瞬` `弱気` `生き方`） | N2 / N3 |
| 汉字词但中文母语者能猜（`自由` `地図`） | N4 |

同一首歌里 `lv` 的分布最好接近 **N5/N4 占一半、N3 占三成、N2/N1 占两成**。全是 N3 说明你没认真分。

## 四、语法条：`warn` 写"错在哪"

`warn` 不是百科词条，是**纠错提示**。

- 坏：`「ば」是表示假定条件的助词。`
- 好：`口语里同样的意思更常用「たら」；「ば」偏书面、条件性强。`
- 好：`「しか」必须跟否定呼应，缺了否定就错句。`
- 好：`「なんか」是「など」的口语形，把对象往下压。`

`form` 要给**完整接续**，包括不规则：`五段：词尾变え段 ／ 一段：＋ろ ／ する：しろ・せよ`。

`eg` 用歌里的原句，不带注音，方便对照卡片。

## 五、出题：先保证唯一解

> 只在 `modules.quiz` 开着时做。关掉时 `song.json` 可以不写 `quiz`，build 不会报错。

### 好用的五种空位

| 类型 | 例子 | 考什么 |
|---|---|---|
| 接续 | `弱気【な】君を` | な形容词修饰名词 |
| 助词 | `君【に】しかできない` | 固定搭配里的助词 |
| 活用 | `歩き続【け】よう` | ます形 + 继续体 |
| 句尾 | `武器になる【から】` | 句末省略 |
| 副词/程度 | `晴れの日【ばかり】じゃない` | 部分否定 |

### 三个禁忌（全部踩过）

1. **一题多解**。`光がなくせ【】ように` 填 `ぬ` 和 `ない` 都对 → 废题。改成 `なく【せ】ぬ`，唯一解。
2. **答案扎堆**。12 题正确答案全在第 1 位。运行时虽会打乱，作者侧仍要人工打散，否则审题时看不出问题。
3. **考背诵不考语法**。`描いた【夢】を` 里 `星` 也成立 → 坏题。改成 `描いた夢【】` 考宾格 `を`。

### `why` 的写法

两句话：**为什么是这个** + **为什么不是别的**。

> 「続ける」是二类动词，接在ます形后变成「続け＋よう」。歩く→歩き＋続ける→歩き続ける。

> 「なくす」→可能形「なくせる」→文言否定「なくせぬ」。这里挖的是可能形词尾「せ」。

## 六、文案：别写成模板腔

`map.why` 四条理由和 `steps` 三步，每首歌都要重写。`listen` / `plan` 只在对应模块开着时才写。

**关掉板块时，文案要跟着改**：`steps` 第三步别再喊「去做测验」，改成「回到词表把没勾的过一遍」——页面上没有的东西不要提。

`map.why` 四条理由、`steps` 三步、`listen` 六张卡、`plan` 七天，每首歌都要重写。

**`why` 四条理由的排序**：语法密度 > 词汇重复率 > 语音难度 > 情绪/跟读价值。四条里至少两条要引用**这首歌的具体内容**（哪句、哪个词），不能是通用评价。

- 坏：`这首歌旋律优美，适合学习。`
- 好：`「自分」「夢」「勇気」「ハート」反复出现。同一个词在不同段落听到三四次，比背单词书十遍有效。`

**`listen` 六张卡**：长音 / 促音 / 表记 / 句尾 / 训练法 / 音域。每张的例子必须来自这首歌，`ex` 里放真实词例。

**`plan` 七天**：Day 1 只听不查词；Day 2–3 分段精读；Day 4 语法过一遍；Day 5 测验回查；Day 6 跟读；Day 7 默写输出。天数可以调，但**最后一天必须是"不看页面输出"**。

## 七、版权

- 单卡引用 ≤ 一行，整页引用总量 ≤ 原词 1/3。
- 不在页面上放完整歌词、不做"歌词全文"页、不提供歌词下载。
- 需要全文对照时，引导用户用**粘贴工作台**（浏览器本地处理，不上传）。
- `footer.note` 用 SKILL.md 里的标准句，作者名要写全。
