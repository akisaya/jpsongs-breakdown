# 编辑口径

这份文件回答的是"内容怎么写才不水"。schema 决定页面长什么样，这里决定它值不值得学。

## 一、选句：什么句子配得上一张卡

先判断整首歌：语速中低速、咬字清晰、副歌有重复句式、语法点集中在 N4–N3，才撑得起一页。
饶舌 / 大量方言古语 / 满篇拟声词，做出来只有「翻译」没有「教学」——直接告诉用户换一首。
常见规模是 16–24 张完整行卡、50–70 个词、12–16 条语法。不同歌词行更多时可以适当超过 24 张；不能为了守住数量而合并不同变体或截成短语。

**值得做卡的三个信号**

1. **一句里叠了两层以上语法**。`なくせぬ` = 可能形 + 文言否定；`なれるさ` = 可能形 + 终助词。这种句子讲一次抵三句。
2. **中文直译会走样**。`嘘じゃない` 直译"不是谎话"，实际是"都是真的"。学习者自己看翻译永远学不会。
3. **有日语特有的"句法习惯"**。宾语甩到句末（`つかめ! 描いた夢を`）、句尾用 `から` 留白、用片假名做强调（`コト`）。

**不值得单独拆成片段的信号**

- 纯名词短语（`青い星に`）——没有语法可讲。
- 只有一个 N4 词汇、没有句型的句子——那是词表的活。
- 歌词里重复出现的段落——同一句只做一张卡，别做两遍。

**一张卡就是一条完整歌词行**：`lines[].jp` 去掉注音、忽略空白后，必须与
`lyrics.blocks[].lines` 中的一条完全相同。不能把「宵闇に 爪弾き」缩成「宵闇」或「爪弾き」，
也不能把相邻两行拼成一张卡。

- 一句里有两个以上语法时，仍保留整句，只选一个讲解重点；另一个语法留在 `n` 或语法图谱里。
- 一行太长时，完整保留原文，通过 `g` / `n` 拆解结构，不靠截短歌词来降低难度。
- 完全相同的歌词行只做一张卡；措辞、省略或语序不同的变体属于不同来源行，需要分别处理。
- 用户要求“逐句精读”时，导航、章节标题和主按钮统一写「逐句精读」，不能只改名称而保留短语卡。

**抽卡的分布**：按歌词出现顺序选完整行，覆盖助词、时态、活用、句型与语气。通常 16–24 张；
若不同歌词行更多，可以超过 24 张，不能为了守数量把完整句拆成多个片段。不按曲式分配配额，也不需要判断段落类型。

## 二、卡片：`g` 和 `n` 必须分工

这是整套模板最容易被写坏的地方。

| 字段 | 回答的问题 | 长度 |
|---|---|---|
| `g`（语法） | 这个句型**是什么、怎么接** | 30–60 字 |
| `n`（语感） | 唱到这一句**要注意什么** | 30–60 字 |

**正例**

> `g`：**〜たり〜たりする**：从一堆动作里挑两三个举例，暗示"还有别的"。歌词只留了一个「たり」，第二个被省略了。
> `n`：「コト」特意写成片假名，不是错字，是为了让这个词在视觉上被顶出来，唱到这里语气也更实。

**反例**（`n` 把 `g` 又说了一遍）

> `g`：命令形，つかむ → つかめ。
> `n`：这里是命令形，表示"抓住"。

`n` 的四个合法方向，选一个写：

1. **唱法**：哪里换气、哪个音要拖满、哪个促音卡鼓点。
2. **书写**：片假名强调、送假名、旧字。
3. **语气**：`さ` 像中文的"嘛"、`から` 收得轻。
4. **对比**：`逢う` vs `会う`、`壊す` vs `崩す`、`だけ` vs `にしか`。

写不出 `n`，说明这个句子不值得做卡，换一句。

## 三、词表：收词与分级

**收**：这首歌里出现、且会挡住 N3 学习者理解的词。动词优先于名词，因为动词带活用。

**不收**：`する` `いる` `ある` `こと` `もの` `とても` 这类。也不收只在歌词里出现一次、且不影响理解的生僻词。

**分级保守原则**：拿不准就给低一级。

| 情况 | 给 |
|---|---|
| 日常会话高频、N4 教材里出现过 | N4 或 N5 |
| 书面语/文学语（`宿る` `鼓動` `逢う` `たくましい`） | N2 或 N1 |
| 抽象名词（`一瞬` `弱気` `生き方`） | N2 / N3 |
| 汉字词但中文母语者能猜（`自由` `地図`） | N4 |

同一首歌里 `lv` 的分布最好接近 **N5/N4 占一半、N3 占三成、N2/N1 占两成**。全是 N3 说明你没认真分。

**排序与去重**：按歌词出现顺序排（不按五十音），学习者是对着歌记的；同一个词反复出现也只收一次。总量 50–70。

## 四、语法条：`warn` 写"错在哪"

`warn` 不是百科词条，是**纠错提示**。

- 坏：`「ば」是表示假定条件的助词。`
- 好：`口语里同样的意思更常用「たら」；「ば」偏书面、条件性强。`
- 好：`「しか」必须跟否定呼应，缺了否定就错句。`
- 好：`「なんか」是「など」的口语形，把对象往下压。`

`form` 要给**完整接续**，包括不规则：`五段：词尾变え段 ／ 一段：＋ろ ／ する：しろ・せよ`。

`eg` 用歌里的原句，不带注音，方便对照卡片。

**同一句型只出现一次**：`〜よう` 与 `〜う` 合成一条，别为了凑数拆开。总量 12–16 条。

每条语法的 `examples` 写 **2–3 个独立例句**，不把歌词原句算进数量：

- 日文例句用常见语境，汉字注明假名；中文译文对应整句意思。
- 同一条的例句采用不同词汇或场景，不能只替换主语凑数。
- 例句应确实展示该句型；合并介绍命令与禁止、不同接续或缩约变体时，覆盖相应用法。
- 文语、粗犷口语等特殊语体要说明语气或适用场景。
- 原创例句，不额外复制歌词；先核对日语接续、活用、注音和译文，再写入数据。

## 五、文案：别写成模板腔

`map.why` 四条理由和 `steps` 三步，每首歌都要重写。步骤对应听歌、逐句精读、回看词汇或语法例句。
写不出四条站得住的理由，说明这首歌不该做。


**`why` 四条理由的排序**：语法密度 > 词汇重复率 > 语音难度 > 情绪/跟读价值。四条里至少两条要引用**这首歌的具体内容**（哪句、哪个词），不能是通用评价。

- 坏：`这首歌旋律优美，适合学习。`
- 好：`「自分」「夢」「勇気」「ハート」反复出现。同一个词在不同段落听到三四次，比背单词书十遍有效。`



## 六、版权

- **默认收录完整歌词**，按核对后的原文顺序写入 `lyrics.blocks`。只有用户明确要求省略时才关闭全文；省略全文的页面，单卡引用 ≤ 一行，整页引用总量 ≤ 原词 1/3。
- 加了完整歌词，`footer.note` 必须写全作词 / 作曲 / 演唱，并注明「仅供学习参考，请勿用于商业用途」。标准句式：

  > 本页为个人日语学习用途的歌词解析作品，非官方发布。歌词著作权归作词 X、作曲 Y、演唱 Z 及相关权利方所有；页面内容仅供学习参考，请勿用于商业用途，并请通过正版音源与官方歌词页对照收听。
- 页面要上公开域名（Pages 等）时，**先提醒用户**：完整歌词公开传播和个人本地学习不是一回事，选不选由他定。

## 七、交付前自检

```
[ ] 每张卡的 n 都不是 g 的复述
[ ] 每张卡的 jp 是完整歌词来源行，不是词组、半句或跨行拼接；`--strict-lines` 无错误
[ ] 每条语法有 2–3 个独立例句，注音与中文译文正确
[ ] 例句接续与该语法的说明一致，正文在语法图谱结束
[ ] 词表 lv 分布合理（不是一水 N3）
[ ] why 四条理由里至少两条引用了具体歌词
[ ] 默认完整歌词已收录，原文换行与段落顺序保留，没有额外的曲式分类；省略全文须有用户明确要求
[ ] footer 版权句写全了作词/作曲/演唱，且与「有无完整歌词」一致
[ ] check.js 全绿，preview 截图肉眼过一遍
```
