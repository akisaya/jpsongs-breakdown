# 已知坑

分两类：**内容侧**（写 `song.json` 时会踩，`build.js` 多数会告警或报错）
和**模板侧**（只有改 `assets/base.css` / `assets/render.js` 才会踩，不报错，只在小屏上表现为溢出、错位）。

## 内容侧

| 坑 | 现象 | 解法 |
|---|---|---|
| 答案扎堆 | 12 题正确答案全在第 1 位 | 作者侧打散；`build.js` 会告警 |
| 一题多解 | 学习者选对了却被判错 | 换一个唯一解的空位 |
| 状态串歌 | 换歌后掌握度串了 | `render.js` 按 `meta.slug` 加 localStorage 前缀，**slug 必须每首歌不同** |
| 合集页没进度条 | 曲目卡上的掌握度不显示 | 合集页读 `jss.<SONGS[].slug>.mastery`，所以 `SONGS[].slug` 必须等于 `meta.slug`（目录名可以不同） |
| 板块数对不上 | 页面只剩 3 块 / 导航多一项 | `modules` 关掉的板块会把数据一起剔除；`stats` 项要给 `"module":"quiz"` 才会跟着消失 |

## 模板侧（改样式或交互时看）

| 坑 | 现象 | 解法 |
|---|---|---|
| 媒体查询位置 | `@media` 里的规则被后面同权重的基础规则覆盖 | 媒体查询放到基础规则**之后**，或提高选择器权重（`.q .q-opts`） |
| 内联 flex-grow | 媒体查询里的 `flex` 简写压不过内联 `flex-grow` | 内联只写 `style="--w:28"`，CSS 用 `flex-grow:var(--w,1)` |
| `1fr` 的隐式最小宽 | 带 `nowrap` 的子元素把网格撑破，移动端横向溢出 | `minmax(0,1fr)` + 网格子项 `min-width:0` |
| 伪元素定位 | `::after` 用了 `inset:0` 之后再设 `right/top`，会被 `left:0` 拉回左上角 | 需要独立定位的装饰做成真实元素（如 `.cover-ring`），伪元素只留铺满的高光 |
